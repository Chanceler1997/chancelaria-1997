# Chancelaria 1997 v7.0.5

Versão de restauração dos dados antigos.

## Restauração no primeiro acesso

1. Abra a Chancelaria 1997.
2. Toque em `Restaurar backup antigo`.
3. Selecione `backup_chancelaria_1997.json` no celular.
4. A tela confirma a quantidade de registros encontrada.
5. Crie e confirme a nova senha mestra.
6. Toque em `Criar proteção e restaurar`.

O backup não faz parte do repositório GitHub. O arquivo é lido localmente e os dados são gravados no cofre criptografado do aplicativo ou navegador.

Backup validado para esta recuperação: 25 Irmãos, 3 sessões, 3 conjuntos de presenças e 8 datas.

## Persistência

O namespace `chancelaria1997_v704_recuperacao_` foi mantido de propósito. As próximas atualizações da linha 7 não devem trocar esse namespace. Isso evita que uma atualização esconda os dados já restaurados.
