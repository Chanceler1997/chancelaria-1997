# Chancelaria 1997 v7.0.6

Versão de estabilização após a restauração dos dados.

Correções desta revisão:

1. O cofre já restaurado continua no namespace `chancelaria1997_v704_recuperacao_`.
2. A tela de login não mostra mais o botão de restauração. Backup e recuperação permanecem na área Mais.
3. Os cartões de Sessões usam layout móvel em duas linhas e não comprimem o título.
4. O WebViewer usado para gerar PDF ocupa a tela durante a captura, enquanto o WebViewer principal fica oculto.
5. A geração aguarda imagens, fontes e ciclos de pintura antes de sinalizar prontidão ao Android.
6. A versão da URL muda para 7.0.6, impedindo o reaproveitamento do PDF em branco armazenado na versão anterior.
